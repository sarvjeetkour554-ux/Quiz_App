# Quiz App

A simple and interactive Quiz App built using HTML, CSS, and JavaScript.

The app allows users to choose a programming/web development topic and attempt a 10-question multiple-choice quiz.

LIVE APP URL()

## Features

- Six different quiz topics:
  - HTML
  - CSS
  - JavaScript
  - Java
  - C++
  - Python
- 10 questions for each topic
- One question displayed at a time
- Previous and Next navigation
- Answer selection using radio buttons
- Automatic score calculation
- Result page displaying the final score
- Simple and beginner-friendly user interface
- Responsive layout

## Technologies Used

- HTML5
- CSS3
- JavaScript
